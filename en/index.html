Mateus Vitor ↗

Anápolis, Goiás · Brazil

I’m a front-end developer and web designer based in Brazil. I turn product requirements into clear, reusable interfaces with HTML, CSS, JavaScript, TypeScript, React and Next.js.

I created NocturnShop, my own SaaS product. My hands-on work covers landing pages, dashboards, marketplace interfaces and responsive web applications, connecting the interface to APIs, authentication, data, payments and automations.

I focus on mobile-first design, reusable components, performance, technical SEO and accessibility. I’m available for freelance projects and development opportunities, from a focused landing page to an interactive web application.
