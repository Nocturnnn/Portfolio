Calm Access Login

Interface de login pensada para tornar a experiência de acesso mais suave, clara e acolhedora, sem abrir mão de detalhes práticos que ajudam no uso real do dia a dia.

Visão Geral

O projeto foi criado para mostrar como uma tela de login pode ir além do básico. A proposta combina visual limpo, organização cuidadosa e pequenas interações que ajudam o usuário a entender melhor o fluxo e reduzir atrito durante o acesso.

No momento, a autenticação ainda está simulada no frontend, mas a base estrutural já está pronta para evoluir para integração real no futuro.

Principais Recursos

  • Login com email ou nome de usuário.
  • Validação local dos campos.
  • Mostrar e ocultar senha.
  • Indicador de força da senha.
  • Alerta de Caps Lock ativo.
  • Modo de recuperação de senha.
  • Feedback visual de erro, sucesso e informação.
  • Conta demo para teste rápido e lembrar acesso com localStorage.
